# shift_tool

薬剤部の月次勤務表を自動作成するツールです。スタッフ条件と希望を読み込み、専属業務・兼務業務・ペア当直の制約を OR-Tools CP-SAT で最適化します。

## 実行

Python 3.12 以降と [uv](https://docs.astral.sh/uv/) を使用します。リポジトリのルートで依存関係を同期し、起動してください。

```bash
uv sync
uv run main.py
```

起動後、対象年と対象月を入力します。月は1～12のみ指定できます。ソルバーの探索時間上限は300秒、相対ギャップ上限は3%です。最適解または実行可能解が得られた場合に結果を出力します。

## 入力ファイル

起動後、スタッフ条件ファイルと希望リストをファイル選択ダイアログで指定します。どちらもExcelファイルを選択してください。ファイル名の形式はコードで検証しません。

- スタッフ条件ファイル：`member_list` シートを使用し、先頭行を読み飛ばして読み込みます。
- 希望リスト：2行目を読み飛ばして読み込みます。スタッフ名と日ごとの希望を使用します。

スタッフ条件と希望リストのスタッフ名は一致している必要があります。

月初の勤務制約には、前月の勤務表Excelを選択して使用します。当直履歴には `result/oncall_shift_wide_{年}_{月}.csv` を使用します。さらに、直近12か月分の当直回数を集計するため、当直表Excelを入れたフォルダを選択します。この集計ではフォルダ内の `.xlsx` ファイルをすべて読み込むため、対象の当直表だけを入れてください。

12月・1月の勤務作成では、`result/Shift_cleaned_{年}_{月}.csv` または同名のExcelファイルを年末年始の履歴として参照します。前年12月や前年1月の特定日の勤務者を判定する処理では、前年のスタッフ条件ファイルも参照します。履歴がない場合は引き継ぎを省略する処理とエラーにする処理があります。

## 適用している制約

制約は OR-Tools CP-SAT のモデルに追加されます。必ず守る条件はハード制約として設定し、配置人数の不足、勤務回数の偏り、会議出勤の希望、行事前後の当直回避はソフト制約として目的関数で最小化します。

### 共通条件

- 休職中のスタッフには専属業務、兼務業務、当直を割り当てない。
- `Floor`、`Floor2`、`Floor3` の所属情報に基づいて、専属業務の候補を決める。
- `緩和回診`、`心不全回診`、`ポリファーマシーチーム`、`NST`、`実習`、`マスター管理`、`RI`、`医薬品安全使用WG`、`認知症せん妄ラウンド`、`感染管理,AST` の担当フラグに基づいて、対応する専属業務・兼務業務の候補を決める。
- 1人に同じ日に割り当てる専属業務は1つまでとする。
- 兼務業務は、同日に専属業務へ出勤しているスタッフを候補とする。
- 日曜・祝日と年末年始の対象日は、1-2階、3階、4階、5階、化療、DI、入退院センター、医療安全・感染管理、ポリファーマシーを通常配置しない。
- 日曜・祝日の専属業務の出勤希望は、調剤室またはDIに対応可能なスタッフだけを対象とする。調剤室は `日曜出勤` が有効なスタッフ、または当日の出勤希望があるスタッフを候補とする。
- 12月30日、12月31日、1月2日、1月3日を祝日として扱う。1月1日は日本の祝日判定で扱う。

### 希望と日勤

- 希望記号 `休み`、`指`、`夏`、`有`、`特` は休み希望として扱う。
- 希望記号 `慶`、`慶弔休暇` は慶弔休暇希望として扱う。
- 希望記号 `育`、`育休` は育休希望として扱う。
- 希望記号 `研`、`研修` がある日は専属業務を研修に固定する。
- 希望記号 `学会` がある日は専属業務を学会に固定する。
- 休み、慶弔休暇、育休、研修、学会の希望があるスタッフは、通常業務の配置候補から除外する。
- 希望記号 `出勤`、`出` がある日は、担当可能な専属業務への配置を優先する。日曜・祝日は調剤室またはDIだけを対象とし、該当業務に配置できる候補がいない場合は出勤希望を適用しない。
- `1-2階` は月曜から土曜まで3人を目標とし、配置可能な必須メンバーがいる場合は少なくとも1人を含める。
- `3階` は火曜5人、月曜・水曜・木曜・金曜・土曜は4人を目標とする。
- `4階` は月曜5人、火曜・水曜・木曜・金曜・土曜は4人を目標とする。火曜は緩和回診担当者を候補から除く。
- `5階` は月曜・水曜5人、祝日明けの火曜5人、通常の火曜・木曜・金曜・土曜4人を目標とする。
- `化療` は月曜から金曜まで4人を目標とし、化療担当者に育休希望がある場合は3人を目標とする。土曜は2人を目標とする。
- `DI` は通常、月曜2人、火曜から土曜まで1人を目標とする。薬審対象月の前月にあたる1月・7月・9月・11月は、月末5日間を2人とする。
- `調剤室` は通常の月曜から木曜まで6人、金曜は第1・第3週6人および第2・第4週5人、土曜は3人を目標とする。
- 日曜の `調剤室` は前日が祝日でない場合4人、前日が祝日の場合7人を目標とする。連続する祝日は、直前日の目標人数に応じて7人または4人を目標とする。
- 年末年始の `調剤室` 人数は、日付ごとの年末年始用設定を使う。
- `入退院センター` は祝日・年末年始を除く月曜から土曜まで1人を目標とする。
- `医療安全・感染管理` は祝日・年末年始を除く月曜から土曜まで、候補者がいる日に1人を目標とする。
- 上記の配置人数は不足人数を目的関数で減らす目標であり、候補者が不足する場合にも必ず目標人数を満たすハード制約ではない。
- 課長担当が配置可能な日は、課長業務の未配置を目的関数で減らす。
- 当直明けを勤務日に数えた7日間の勤務日数が6日を超える場合にペナルティを加える。日曜・祝日勤務は月1回を超える分にペナルティを加える。
- 専属業務の担当回数、連続勤務日数、連続休務日数のスタッフ間の偏りを目的関数で抑える。

### 当直

- 毎日、当直ペアをちょうど1組割り当てる。1人が同じ日に複数のペアへ入ることは禁止する。
- 当直ペアは同性に限る。
- 当直不可のスタッフと休職中のスタッフは当直候補から除外する。
- `Floor` が外来または部長で、かつ主任以上のスタッフは月1回までとする。それ以外のスタッフは月2回までとする。月1回以上の担当は必須にしない。
- 当直ペアの同一フロア、主任以上同士、同期同士の組み合わせは、目的関数のペナルティで減らす。
- 希望記号 `当直不可`、`当×`、`×`、`出当×` に含まれる当直不可希望の日は当直にしない。
- 希望記号 `休み`、`指`、`夏`、`有`、`特`、`慶`、`慶弔休暇`、`育`、`育休`、`研`、`研修`、`学会` の日は当直にしない。これらの希望日の前日も当直にしない。
- 希望記号 `出勤`、`出`、`AM出`、`AM出勤`、`PM出`、`PM出勤` の前日は当直にしない。
- 希望記号 `当直`、`◎`、`当` は当直希望として扱う。当直希望は目的関数で優先するが、7日間隔やペア条件と両立しない場合は未達になる。希望者が同日に3人以上いる場合は、月間回数の公平性を考慮して2人までを選ぶ。
- 同じスタッフの当直間隔は7日以上とする。月初の当直可否判定には前月末8日分の当直履歴を参照する。
- 当直の翌日は専属業務を `明け` に固定し、他の専属業務を割り当てない。前月末日に当直をしたスタッフは当月1日も `明け` として扱う。
- `明け` の翌日は休みを目的関数で優先する。
- 通常スタッフの過去分と当月分を合算した当直回数の最大値と最小値の差を目的関数で抑える。主任以上と外来担当者はこの公平性計算から除外する。
- 薬審前日、役職者会議前日・前々日、第2金曜日の病棟担当者カンファレンス前日・前々日、第3金曜日の臨床薬剤課会議前日・前々日、第4金曜日の医薬品安全使用WG前日・前々日、ポリファーマシー開催日前日・前々日、認知症せん妄ラウンド前日・前々日、緩和回診前日・前々日、AM出勤希望の前々日、PM出勤希望の前々日は、対象者の当直を目的関数で避ける。

### 兼務業務と会議

- `RI` は祝日を除く月曜から土曜に1人を目標とする。対応可能者がいない日は未配置を許容し、対応可能者の中では `RI優先度` の小さい値を優先する。
- 火曜のポリファーマシーは、非祝日でチーム全員が配置可能な日に開催し、開催日はチーム全員を配置する。月内に開催可能日があれば1回開催する。
- 金曜のポリファーマシーは、非祝日でチーム全員が配置可能かつ当直明けのスタッフがいない日に開催する。開催日はチーム全員を兼務業務に配置し、月内に開催可能日があれば1回開催する。
- 火曜・金曜のポリファーマシー開催は、休み、育休、慶弔休暇、研修、学会の希望者がいる日には行わない。
- 火曜・金曜の認知症せん妄ラウンドは、非祝日に配置する。配置可能なスタッフがいる場合は最低1人を割り当て、配置可能者全員の参加を目的関数で促す。
- 第4金曜日の医薬品安全使用WGは、担当フラグがあるスタッフを候補として、参加者数を目的関数で増やす。
- 火曜の心不全回診は、対応可能者から最大1人を配置する。
- 緩和回診担当者は、火曜に専属業務の緩和回診を担当する。木曜は調剤室と緩和回診の兼務に配置する。月曜が祝日の場合は調剤室と緩和回診の兼務に配置する。
- 感染管理・ASTは月曜・水曜・金曜に最大1人を配置する。PM出勤希望者がいる場合はそのスタッフを優先する。
- 監査AMと監査PMは、日曜・祝日を除き、調剤室または当日の化療配置者から各1人を選ぶ。1人が同日に監査AMと監査PMを兼ねることはできない。土曜の監査AMは当日の化療配置者、監査PMは当日の調剤室配置者を候補とする。
- 監査AM・PMは、4月から7月までの各月15日以前は同期変数が0のスタッフを候補から除外する。
- 役職者会議は第1・第3・第5月曜の主任以上を対象とし、休み、育休、慶弔休暇、研修、学会の希望がないスタッフの出勤と会議配置を促す。外来所属者は対象外とする。
- 第2金曜日の病棟担当者カンファレンスは、主任以上でDIと課長の両方に所属するスタッフの出勤を促す。
- 第3金曜日の臨床薬剤課会議は、主任以上のうち外来、化療、部長に該当しないスタッフを対象に、出勤と会議配置を促す。
- 第4金曜日の薬剤部連絡会は、主任以上の出勤を促す。
- 偶数月の第1木曜日の薬審は、主任以上の出勤と兼務業務への配置を促す。休み、育休、慶弔休暇、研修、学会の希望があるスタッフは対象外とする。
- DIと課長の両方に所属するスタッフは、16日から23日までの出勤を促す。休み、育休、慶弔休暇、研修、学会の希望がある日は対象外とする。

### 目的関数で調整する条件

- 専属業務の必要人数に対する不足
- RI、医薬品安全使用WG、認知症せん妄ラウンド、心不全回診、緩和回診、感染管理・AST、課長業務の未配置
- 専属業務の担当回数の偏り
- 監査、心不全回診、感染管理・ASTの担当回数の偏り
- 連続勤務が6日を超える日数
- 日曜・祝日勤務が月1回を超える回数
- 連続勤務日数と連続休務日数のスタッフ間の偏り
- `明け` の翌日の休み未配置
- 当直希望の未達
- 当直回数の偏り
- 同フロア、主任以上同士、同期同士の当直ペア
- 薬審、会議、回診、ポリファーマシー、AM出勤希望、PM出勤希望の前日または前々日の当直
- 役職者会議、病棟担当者カンファレンス、臨床薬剤課会議、薬剤部連絡会、薬審、DI・課長の月中出勤希望

実行可能解がない場合に、ハード制約を自動でソフト制約へ変更する処理はありません。希望、当直の月間回数上限、当直可能スタッフ数、担当可能業務を確認してください。

## 出力

解が得られると、以下を `result/` に保存します。`YYYY_MM` は対象年と2桁の月です。

- `Shift_YYYY_MM.csv`：スタッフ・日付ごとの専属業務、兼務業務、当直の明細
- `Shift_wide_YYYY_MM.csv`：専属業務の日付横持ち表。翌月の月初制約でも参照します。
- `Shift_cleaned_YYYY_MM.csv`：勤務表への転記向けに整形した専属業務表
- `oncall_shift_long_YYYY_MM.csv`：当直の縦持ち表
- `oncall_shift_wide_YYYY_MM.csv`：当直の日付横持ち表とスタッフごとの当直回数
- `result/weekly/Shift_week_YYYY_MM_weekN.xlsx`：週ごとの勤務表

実行ログは `logs/shift_run_{実行日時}.txt` に保存されます。
## 構成

- `main.py`：年月入力、データ読み込み、最適化実行、結果出力
- `optimizer/`：最適化モデルと制約
- `config/`：専属業務、兼務業務、希望記号の定義
- `requests/`：希望・追加条件の処理
- `result/`：生成結果と月次引き継ぎ用ファイル
