# shift_tool

薬剤部の勤務表（専属業務・兼務業務・当直）を、
制約条件と希望に基づいて自動作成するツールです。  
OR-Tools（CP-SAT）を使って、月次シフトを最適化します。

## 概要

- スタッフ条件（対応可能業務・当直可否など）を読み込み
- 休み希望／勤務希望を反映
- 専属業務・兼務業務・当直の割り当て制約を適用
- 解が見つかればCSV形式で結果を出力

主な処理は `main.py` から実行され、`optimizer/` 配下の各制約クラスでモデルを構築します。

## このツールで扱う勤務カテゴリ

- 専属業務（例：調剤室、監査、入退院センター、各病棟、DI など）
- 兼務業務（例：心不全回診、NST回診、ICT回診、RI、会議系 など）
- 当直（ペア当直）

業務マスタは `config/sections.py` と `config/concurrent_sections.py` で管理しています。

## 入力ファイル（現行実装）

- `スタッフ条件.xlsx`
    - スタッフ情報・対応可能業務など
- `希望リスト_テスト.xlsx`
    - 日ごとの希望（休み／勤務希望）

※ `main.py` では現在、対象年月が `2026年1月` で固定されています。

## 出力ファイル

実行後、`result/` に以下を出力します。

- `Shift_YYYY_MM.csv`：スタッフ×日付の明細（専属・兼務・当直）
- `Shift_long_YYYY_MM.csv`：専属業務の横持ち形式
- `oncall_shift_YYYY_MM.csv`：当直結果（横持ち＋当直回数）

また、実行ログを `logs/shift_run_*.txt` に保存します。

## 実行方法

依存関係をインストール後、以下で実行します。

```bash
uv run main.py
```

## 主要ディレクトリ

- `optimizer/`：最適化モデルと制約定義
- `config/`：業務区分やマッピング定義
- `requests/`：希望・追加条件の整形
- `result/`：生成されたシフトCSV
- `logs/`：実行ログ

## 使用ライブラリ

- `ortools`
- `pandas`
- `openpyxl`
- `jpholiday`
