# shift_tool

薬剤部の月次勤務表を自動作成するツールです。スタッフ条件と希望を読み込み、専属業務・兼務業務・ペア当直の制約を OR-Tools CP-SAT で最適化します。

## 実行

Python 3.12 以降と [uv](https://docs.astral.sh/uv/) を使用します。リポジトリのルートで依存関係を同期し、起動してください。

```bash
uv sync
uv run main.py
```

起動後、対象年と対象月を入力します。月は1～12のみ指定できます。ソルバーの探索時間上限は300秒、相対ギャップ上限は3%です。最適解または実行可能解が得られた場合に結果を出力します。

## 入力ファイル

対象年月に対応する次のExcelファイルを、リポジトリのルートに置いてください。ファイル名の月部分はゼロ埋めしません。

- `スタッフ条件_テスト_{年}_{月}.xlsx`：`member_list` シートを使用します。先頭行を読み飛ばし、スタッフ名や対応可能業務などを読み込みます。
- `希望リスト_テスト_{年}_{月}.xlsx`：先頭行を読み飛ばし、スタッフ名と日ごとの希望を読み込みます。

たとえば2026年9月分では `スタッフ条件_テスト_2026_9.xlsx` と `希望リスト_テスト_2026_9.xlsx` を参照します。スタッフ条件と希望リストのスタッフ名は一致している必要があります。

月初の勤務制約には、`result/` 内の前月シフト `Shift_wide_{年}_{月}.csv` および当直 `oncall_shift_wide_{年}_{月}.csv` を参照します。12月・1月の年またぎ処理や前年同日の条件では、前年の `Shift_cleaned_年_月.csv` とスタッフ条件ファイルも参照する場合があります。これらの履歴ファイルがない場合は、処理によって引き継ぎを省略するかエラーになります。

## 適用している制約

制約は OR-Tools CP-SAT のモデルに追加されます。希望や配置条件の一部はハード制約、勤務回数・公平性・行事前後の当直回避などはソフト制約として目的関数のペナルティに加算されます。

### 共通・資格条件

- 休職中のスタッフは専属業務・兼務業務・当直の対象外にする。
- `Floor`、`Floor2`、`Floor3`、各担当フラグに基づき、担当可能な専属業務・兼務業務だけを割り当てる。
- 1人に1日1つの専属業務だけを割り当てる。
- 兼務業務は、同日に専属業務へ出勤しているスタッフだけを対象にする。
- 日曜・祝日は通常の病棟業務を休みにし、必要な日曜・祝日業務だけを配置する。12月30日・31日、1月2日・3日も特別な祝日として扱う。

### 希望・日勤

- 休み、慶弔休暇、育休の希望日は専属業務を割り当てない。
- 研修希望日は専属業務を研修に固定し、他の業務を割り当てない。
- 学会希望日は専属業務を学会に固定し、他の業務を割り当てない。
- 出勤希望日は、スタッフが担当可能な専属業務へ配置する。日曜・祝日は調剤室またはDIだけを対象にする。
- 専属業務ごとに曜日・祝日・前日祝日・年末年始を考慮した必要人数を確保する。対象は1-2階、3階、4階、5階、化療、DI、調剤室、入退院センター、感染管理など。
- 1-2階には必須メンバーを可能な範囲で含める。DI、課長、RIなどの担当条件も配置候補の判定に反映する。
- 連続勤務を抑制し、日曜・祝日の勤務回数をできるだけ月1回以内にする。
- 専属業務の割り当て数、連続勤務、連続休務のスタッフ間の偏りを抑える。

### 当直

- 当直は1日1ペア、1日あたり1人以上2人以下とする。
- 当直不可または休職中のスタッフを当直候補から除外する。
- 当直ペアは同性に限定する。主任以上同士、同じ同期、同じフロアの組み合わせはできるだけ避ける。
- 外来・部長など対象となる役職者は月1回まで、それ以外のスタッフは月2回までとする。
- 直近12か月分の当直表を指定フォルダから読み込み、主任以上を除くスタッフについて、過去分と当月分の累計回数が均等になるよう調整する。指定フォルダには集計対象の当直表だけを入れる。
- 当直希望、当直不可、休み、慶弔休暇、育休、研修、学会の希望日には当直を割り当てない。休み等の希望日の前日も当直を避ける。
- 前回の当直から次回の当直まで、原則7日以上空ける。月初は前月末の当直履歴も参照する。
- 当直日は専属業務の休み・明け・研修・学会にはしない。
- 当直の翌日は明けに固定し、明けの日は専属業務を割り当てない。前月末の当直者にも月初の明けを反映する。
- 明けの翌日は休みを優先する。当直回数、同性・同フロア・役職者・同期のペアリングは目的関数で調整する。
- 薬審、役職者会議、病棟担当者カンファレンス、臨床薬剤課会議、医薬品安全使用WG、ポリファーマシー、認知症せん妄ラウンド、緩和回診、午前・午後出勤希望の前後は、対象者の当直・明けをできるだけ避ける。

### 兼務業務・行事

- RIは月曜から土曜に原則1人配置し、日曜・祝日は配置しない。対応可能者がいない場合は不足を許容し、RI優先度の高いスタッフを優先する。
- ポリファーマシーは、対象者全員が参加可能な非祝日の金曜日に月1回を原則として開催する。休み・研修・学会希望や明けのスタッフがいる日は開催しない。
- 認知症せん妄ラウンドは非祝日の火曜・金曜に配置可能者を配置する。
- 医薬品安全使用WGは第4金曜日に対象者を配置し、未配置者を減らす。
- 心不全回診は火曜午後に最大1人を配置し、緩和回診は曜日ごとの専属・兼務業務へ配置する。
- 感染管理・ASTは月・水・金に最大1人を配置し、午後出勤希望者を優先する。
- 監査は日曜・祝日を除き、調剤室の配置者からAM・PMそれぞれの条件に従って配置する。同一日にAM・PMの重複配置はしない。
- 役職者会議、薬審、臨床薬剤課会議、病棟担当者カンファレンスなどの出勤・兼務配置は、休み等の希望を優先しつつ、可能な限り実現する。

### 目的関数で調整する項目

- 専属業務・兼務業務の必要人数不足および過剰配置
- 連続勤務、日曜・祝日勤務、連続休務の偏り
- 当直回数と当直ペアの偏り
- 各会議・行事の出勤、担当者配置、開催日の条件違反
- RI、監査、心不全回診、医薬品安全使用WG、感染管理・ASTなどの担当回数の公平性

厳密モードで実行可能解がない場合に、現在の実装が自動でハード制約をソフト制約へ変更することはありません。制約を満たす解がない場合は、入力された希望、月間回数上限、当直可能スタッフ数などの見直しが必要です。

## 出力

解が得られると、以下を `result/` に保存します。`YYYY_MM` は対象年と2桁の月です。

- `Shift_YYYY_MM.csv`：スタッフ・日付ごとの専属業務、兼務業務、当直の明細
- `Shift_wide_YYYY_MM.csv`：専属業務の日付横持ち表。翌月の月初制約でも参照します。
- `Shift_cleaned_YYYY_MM.csv`：勤務表への転記向けに整形した専属業務表
- `oncall_shift_long_YYYY_MM.csv`：当直の縦持ち表
- `oncall_shift_wide_YYYY_MM.csv`：当直の日付横持ち表とスタッフごとの当直回数
- `weekly/Shift_week_YYYY_MM_weekN.xlsx`：週ごとの勤務表

実行ログはコード上 `log/` に保存する設定です。
## 構成

- `main.py`：年月入力、データ読み込み、最適化実行、結果出力
- `optimizer/`：最適化モデルと制約
- `config/`：専属業務・兼務業務などの定義
- `requests/`：希望・追加条件の処理
- `result/`：生成結果と月次引き継ぎ用ファイル
