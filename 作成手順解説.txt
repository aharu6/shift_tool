見本.txtにおける勤務表作成プログラムの解説
================================================

このプログラムは混合整数最適化を使用して、スタッフの勤務シフトを自動作成します。

■ 全体の流れ

1. データ読み込み（9-80行目）
2. 変数定義（226-262行目）
3. 最適化モデル構築（362-368行目）
4. 制約条件の設定（370行目以降）
5. 平等性の最適化（773-915行目）
6. 実行と出力（917-933行目）


========================================
1. データ読み込み（9-80行目）
========================================

【配置データの読み込み】
  df = pd.read_csv("配置 見本 - シート1.csv")

  - スタッフ42名の能力情報（夜勤可否、リーダー資格、専門分野など）を読み込み
  - 各列（「夜勤」「遅番」「リーダー」など）から対象スタッフのリストを作成
  - 例：夜勤可能なスタッフのリスト → 夜勤 = [0, 1, 3, 5, ...]
  
  役割列：
    - 夜勤、金土日祝夜、遅番、土遅
    - ヘルパー、リーダー、日勤、若手、一年
  
  専門グループ：
    - chemo, DI, 麻薬, 治験, OPE, 感染, 緩和
    - 産歯, 腎膠, 消糖, 血内, 一外, 整形
    - 脳外, 脳泌, 循環, 呼皮, 眼科

【希望休の読み込み】
  df = pd.read_csv("勤務表2026年1月2月希望休見本 - シート2.csv")

  - スタッフの希望休日情報を取得
  - 「休」「希1」「希2」の日を必須休暇リストに追加
  - 「日」の日を必須日勤リストに追加

3. 最適化モデル構築（362-368行目）
========================================

m = Model(solver_name="CBC")
x = m.add_var_tensor((n0, n1, n2), "x", var_type="B")

【変数の意味】
  - x[i, j, k] = 1 なら、スタッフiの日jにシフトkが割り当てられる
  - x[i, j, k] = 0 なら、割り当てられない
  - 3次元バイナリ変数（42×55×10 = 23,100個の変数）


========================================
4. 制約条件の設定（370行目以降）
========================================

【基本制約】

(1) 必須休暇の設定（373-377行）
    for i0, rest_days in enumerate(must_rest_days):
        for i1 in rest_days:
            m += x[i0, i1, 2] == 1  # 該当日は必ず休み

(2) 必須日勤の設定（380-387行）
    for i0, job_days in enumerate(must_job_days):
        for i1 in range(n1):
            if i1 in job_days:
                m += x[i0, i1, 0] == 1  # 該当日は必ず日勤

(3) 1日1シフトの制約（389-396行）
    m += xsum(x[i0, i1]) == 1  # 各スタッフは1日に1つのシフトのみ
    
(4) シフト回数の上限
    m += xsum(x[i0, :, 1]) <= 3  # 夜勤3日以下
    m += xsum(x[i0, :, 3]) <= 5  # 遅番5日以下
    m += xsum(x[i0, :, 4]) <= 2  # ヘルパー2日以下
    m += xsum(x[i0, :, 6]) <= 4  # リーダー4日以下


【人数制約】

(1) 平日の人数（397-401行）
    m += xsum(x[:, i1, 1]) == 1  # 夜勤1人
    m += xsum(x[:, i1, 3]) == 1  # 遅番1人
    m += xsum(x[:, i1, 5]) == 1  # 明け1人
    m += xsum(x[:, i1, 6]) == 1  # リーダー1人

(2) 休日の人数（409-420行）
    m += xsum(x[:, i1, 1]) == 1  # 夜勤1人
    m += xsum(x[:, i1, 8]) == 1  # 日勤1人
    m += xsum(x[:, i1, 5]) == 1  # 明け1人

(3) ヘルパー人数（422-476行）
    - 日によって1～4人のヘルパーを配置
    - 一年目は必ず含める（若手育成）


【インターバル制約】

(1) 勤務間インターバル（481-488行）
    # 夜勤・日勤・遅番・ヘルパー後は5日間別シフト禁止
    for shift1, shift2 in product([1, 3, 4, 8], repeat=2):
        if shift1 != shift2:
            m += x[i0, i1, shift1] + sum(x[i0, i1+j, shift2] for j in range(1, 6)) <= 1

(2) 遅番のインターバル（491-495行）
    # 遅番は4日に1回まで
    m += sum(x[i0, i1+j, 3] for j in range(4)) <= 1

(3) 明けの規定（499-502行）
    # 夜勤の翌日は必ず明け
    m += x[i0, i1, 1] == x[i0, i1+1, 5]


【代休ロジック（506-626行）】

土日祝の夜勤・日勤をした人に代休を自動付与：

- 金曜夜勤 → 翌週月曜代休
- 土曜夜勤 → 火曜代休
- 日曜夜勤 → 水曜代休
- 日曜日勤 → 月曜代休
- ヘルパー → 後日代休

例：
  m += x[i0, i1-3, 1] <= x[i0, i1, 7]  # 土曜夜勤なら火曜代休


【リーダーの規定（504-512行）】

リーダーは連続日に同じ人を配置：
  リーダー_days = [[0,1], [2,3], [4,8], ...]  # リーダー担当期間
  
  - 各期間の最初の日に1人割り当て
  - その人が期間中ずっとリーダーを担当


【個人制約】

(1) 夜勤制約（631-656行）
    - 夜勤免除者：完全禁止
    - 一年目：前半30日で1回、後半30日で1回
    - それ以外：2回以下

(2) 土日祝夜勤制約（659-667行）
    - 土日祝夜勤免除者：完全禁止
    - それ以外：1回以内

(3) 金曜夜勤制約（669-677行）
    - 一年目・二年目：金曜夜勤禁止

(4) 日勤制約（681-691行）
    - 日勤免除者：完全禁止
    - それ以外：1回以下

(5) 遅番制約（694-717行）
    - 遅番免除者：完全禁止
    - 一年目：前半30日で1回、後半30日で1回（土曜禁止）
    - それ以外：2回以下（土曜は1回以下）

(6) ヘルパー制約（719-727行）
    - ヘルパー可能者：1回以下
    - それ以外：完全禁止

(7) リーダー制約（729-732行）
    - リーダー不可者：完全禁止


【グループ制約】

(1) 若手制約（738-741行）
    # 若手が同日に夜勤と遅番に入らないように
    m += xsum(x[i0, i1, 1] for i0 in wakate) + xsum(x[i0, i1, 3] for i0 in wakate) <= 1

(2) 専門グループ制約（755-770行）
    # 各専門グループは最低人数を確保
    # 2人グループ：1人以上
    # 3人グループ：2人以上
    # 4人グループ：2人以上


========================================
5. 平等性の最適化（773-915行目）
========================================

【前回実績の読み込み】
  df = pd.read_csv("勤務表2026年1月2月希望休見本 - シート3.csv")
  
  前回の夜勤・日勤・遅番・リーダー・ヘルパーの回数を取得

【最大・最小値変数の定義】
  max_night, min_night = m.add_var(...), m.add_var(...)
  max_day, min_day = m.add_var(...), m.add_var(...)
  max_oso, min_oso = m.add_var(...), m.add_var(...)
  max_leader, min_leader = m.add_var(...), m.add_var(...)
  max_he, min_he = m.add_var(...), m.add_var(...)
  max_土日祝, min_土日祝 = m.add_var(...), m.add_var(...)

【制約の追加】
  各グループ（夜勤可能者、日勤可能者など）ごとに：
    - 今回の回数 = 前回の回数 + 今月の回数
    - その最大値と最小値を変数に設定

【目的関数】
  m.objective = maximize(
      - (max_night - min_night) * 3      # 夜勤の平等性（重み3）
      - (max_day - min_day) * 1.0        # 日勤の平等性
      - (max_oso - min_oso) * 2          # 遅番の平等性（重み2）
      - (max_leader - min_leader) * 1.0  # リーダーの平等性
      - (max_he - min_he) * 1.0          # ヘルパーの平等性
      - (max_土日祝 - min_土日祝) * 1.0  # 土日祝の平等性
  )
  
  → 各シフトの最大回数と最小回数の差を最小化
  → スタッフ間の負担を均等化

========================================
■ プログラムの特徴
========================================

1. 複雑な制約を同時に満たす
   - 人員配置（各日の必要人数）
   - 連続勤務禁止（インターバル）
   - 個人の資格・希望
   - 専門グループの最低人数

2. 公平性を追求
   - 夜勤・遅番などの負担を均等化
   - 前回実績を考慮した長期的な公平性
   - 重み付けで優先度を調整可能

3. 実務レベルの機能
   - 希望休の反映
   - 代休の自動付与
   - 若手の育成（ヘルパーに必ず配置）
   - 専門性の維持（各グループの人数確保）

4. 高速な計算
   - CBC（混合整数最適化ソルバー）使用
   - 30秒以内で23,100個の変数を最適化

このプログラムは医療・介護現場の実務レベルのシフト作成を
自動化する高度な最適化システムです。
